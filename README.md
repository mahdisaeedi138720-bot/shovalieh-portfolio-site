# 🌐 Shovalieh Portfolio Site

**وب‌سایت شخصی دوزبانه (فارسی RTL / English LTR)** — معرفی، مهارت‌ها، پروژه‌ها و راه‌های ارتباطی.

**A bilingual (Persian RTL / English LTR) personal portfolio website** — pure HTML, CSS and a few lines of vanilla JS. No frameworks, no build step: open `index.html` and it works.

---

## ✨ صفحات | Pages

| Page | Language | Path |
|---|---|---|
| فارسی | RTL | [`index.html`](index.html) |
| English | LTR | [`en/index.html`](en/index.html) |

## 🚀 اجرا | Run

```bash
# گزینه ۱ — فقط فایل را باز کنید
open index.html

# گزینه ۲ — سرور محلی
python -m http.server 8080
# → http://localhost:8080
```
